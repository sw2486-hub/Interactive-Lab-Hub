How to play & connect the sensors

Each station selects one ingredient. Match all three items on the order and hold the combination for two seconds. After success, press Next order. Demo uses manual buttons and never counts as a hardware test.

Live mode needs a local server that serves this page and bridges MQTT to a Server-Sent Events endpoint. This HTML contains the frontend only: it does not connect directly to the course MQTT broker. The bridge should subscribe to IDD/<your-team>/cocktail/input/+ and forward each validated sensor heartbeat in the following format:

data: {"station":"A","color":"RED","rgb":[131,44,36]}

Use station A, B or C and color RED, GREEN, BLUE, NONE or UNKNOWN. Send a heartbeat every 0.5–1 second, including when the color does not change. NONE/UNKNOWN clears a selection. A device goes offline after five seconds without data. Each Pi requires its own calibration. The optional rgb field contains three finite numbers from 0 to 65535. The endpoint must send Content-Type: text/event-stream. A JavaScript bridge may instead call window.CocktailBar.receive(payload) while Live mode is selected.

For a local Flask server, place this file in templates/ and return it with render_template('color_cocktail_bar.html'). Use the same server origin for /api/events. No Python packages, external fonts or JavaScript libraries are required by the page itself.
